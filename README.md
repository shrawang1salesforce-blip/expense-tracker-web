# Pocket Ledger

A small expense tracker built with plain HTML, CSS, and JavaScript. It runs in
the browser without a build step or a server.

## Run it

Open `index.html` in a browser. Expenses are saved in that browser's local
storage, so they stay on the same device and browser where you entered them.

## What it does

- Add, edit, and remove an expense.
- Filter the list by category and date range.
- See the total and number of expenses that match the current filters.
- Keep expense data between visits with local storage.

There are no external dependencies. Clearing the browser's site data will also
clear saved expenses.
